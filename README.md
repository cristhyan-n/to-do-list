📝 Task Tracker CLI

Ferramenta de linha de comando para gerenciar tarefas, construída com Python puro. As tarefas são armazenadas em um arquivo tasks.json criado automaticamente.

Requisitos
Python 3.x

Comandos:

python main.py add "Tarefa" - Adiciona uma tarefa

python main.py update <id> "Nova descrição" - Atualiza uma tarefa

python main.py delete <id> - Deleta uma tarefa

python main.py get <id> - Busca uma tarefa pelo ID

python main.py done <id> - Marca como concluída

python main.py progress <id> - Marca como em andamento

python main.py todo <id> - Marca como a fazer

python main.py list - Lista todas as tarefas

python main.py list done - Lista concluídas

python main.py list todo - Lista a fazer

python main.py list progress - Lista em andamento

python main.py list delete - Apaga todas as tarefas

Status disponíveis:
todo · progress · done
